高壓多工客服場域之快捷作業工作台

2026.07 – 2026.11（等待服役期間・自主研發專案）

基於 HCI 認知工效理論與 3-Tier 純前端架構之任務動線重構

🛡️ 商業保密與去識別化合規展示 (IP & Confidentiality Notice)

針對客服現場「10+ 視窗頻繁切換」與「高認知負荷」之痛點，自主開發之純前端單頁式（SPA）作業輔助系統。結合 HCI 認知心理學與全鍵盤流導航，經 GOMS/KLM 模型評估，成功將標準操作流程由 14 次點擊（28 秒）壓縮至 2 次點擊（5 秒）。

🛡️ 智慧財產權與商業保密聲明 (IP & Confidentiality Notice)

本專案源於本人在候役期間於某大眾共享運輸企業任職時，利用下班工餘時間獨立構思與撰寫之純前端輔助工具。為嚴格恪守職業道德、商業保密義務與智慧財產權規範，本作品集已將所有企業名稱、內部業務規則及真實語料完全去識別化，不公開任何涉密原始碼與真實業務畫面，僅以「抽象系統架構圖」、「HCI 認知工效設計規範」與「GOMS 量化評估模型」呈現個人之程式邏輯與設計思考。

模組 1：設計背景與核心挑戰 (Problem Space)

從第一線實務觀察出發的痛點定義

在等待服役期間，我進入某大眾共享運輸公司的第一線客服部門工作。在即時接聽電話與處理突發狀況的高壓多工（High-Stress Multitasking）環境中，我發現傳統企業後台多以「資料庫存取」為中心，卻忽略了第一線操作人員的認知極限，導致三大作業瓶頸：

🔄 視窗碎片化 (Window Fragmentation)

單一案件需在工單系統、通訊軟體、費率表與小抄等 10+ 個分頁間反覆切換（Alt-Tab），嚴重打斷短期記憶與專注力。

🧠 認知負荷超載 (Cognitive Overload)

龐雜的 SOP 未經視覺分層，高壓通話下搜尋延遲極高，易引發新手操作焦慮。

⏳ 應變反應延遲 (Response Latency)

大量重複性的手動複製貼上、修改變數與跨區間時間試算缺乏防呆機制，容易產生人為失誤。

模組 2：3-Tier 系統架構與資安設計 (System Architecture)

Privacy-by-Design：零後端、資料不落地的三層式解耦架構

考量企業內部環境對資訊安全與隱私保護的嚴格要求，本系統在架構設計初期即決定採用「純本機端運作（Zero-Backend / Local-First）」策略，分為三大層級：

第一層：介面展示層 (Top Tier - UI Layer)

整合快捷語料網格、毫秒級關鍵字篩選、分類標籤切換與側邊欄輔助小工具，將原本散落於多視窗的資訊收斂至單一工作視窗。

第二層：功能邏輯層 (Middle Tier - Logic Layer)

實作動態變數插值引擎（點擊後自動彈窗填空並合成完整文本寫入剪貼簿）、規則導向之時間與費用計算器、待辦檢核以及離線表單暫存邏輯。

第三層：資料儲存層 (Bottom Tier - Persistence Layer)

完全基於瀏覽器內建之 LocalStorage 與結構化 JSON 設定檔匯出入機制，所有操作皆在本地端記憶體與本機快取完成，不連接任何外部雲端資料庫，從架構源頭杜絕資料外洩風險。

📊 圖 2：3-Tier 純前端架構與零後端 Privacy-by-Design 資安設計圖 (System Architecture)

模組 3：設計產出與 HCI 認知工效實踐 (HCI & UX Artifacts)

將認知心理學轉化為前端介面規範

為了解決「眼、耳、手」同時多工的瓶頸，介面設計嚴格遵循人機互動（HCI）經典理論：

米勒定律 (Miller's Law)

將高複雜度的業務情境依顏色標籤與側邊欄模組進行分組（Chunking），將單一畫面資訊量控制在人類短期工作記憶最佳範圍內。

費茨法則 (Fitts's Law)

擴大高頻率動作（如單擊複製卡片、底部全域簽名列）的點擊熱區（Target Size），並縮短游標移動距離。

漸進式揭露 (Progressive Disclosure)

平時僅呈現關鍵標題，僅在觸發特定含變數卡片時才展開輸入視窗，維持視覺降噪。

全鍵盤流導航 (Keyboard-First Hotkeys)

實作全域鍵盤監聽引擎（如雙擊快速聚焦搜尋列、單鍵切換分類與關閉彈窗），大幅減少雙手在鍵盤與滑鼠間切換的移動成本（Homing Time）。

📊 圖 3：HCI 認知心理學導向之介面組件規範與熱區配置 (HCI & UX Artifacts)

模組 4：GOMS / KLM 量化成效驗證 (Quantitative Evaluation)

以科學量化指標驗證重構成效

本專案導入人機互動領域之 GOMS 與 KLM（Keystroke-Level Model，按鍵層級模型）進行任務時間預測分析：

❌ 重構前（傳統多視窗作業）

需經歷視窗切換、滾動查找、選取複製、切換視窗貼上與手動修改變數等約 14 個操作步驟，平均耗時約 28 秒。

✅ 重構後（快捷工作台）

透過全域快捷鍵定位與單擊卡片自動合成複製，簡化至 2 次核心點擊，耗時縮減至約 5 秒。

🏆 總體效益

單次常規作業時間縮短約 82%，不僅顯著降低第一線人員的認知疲勞，更展現了將軟體工程與認知工效學結合以解決真實世界痛點的實務價值。

專案簡介

這是一個專為國小小朋友設計的 AI 程式開發教學網站。透過這個網站，孩子們可以學習如何利用 GitHub Copilot 與 HTML5/CSS3 技術，在短短 5 分鐘內從零開始打造出一個具備現代感、充滿互動特效的 6x6 打地鼠遊戲。

項目特色

🤖 AI 驅動教學：利用精確的 AI 提示詞 (Prompt Engineering)，引導 GitHub Copilot 撰寫高品質程式碼。

✨ 現代感視覺：採用毛玻璃風格 (Glassmorphism)、全螢幕 6x6 網格與流暢的 CSS 動畫。

💡 低門檻開發：不需要深厚的語法基礎，專注於邏輯思維與素材整合。

🖱️ 互動式體驗：包含角色下載、AI 去背引導、音效整合以及一鍵複製指令功能。

技術棧

  • Frontend: HTML5, CSS3 (Grid & Flexbox), Vanilla JavaScript
  • AI Tools: GitHub Copilot, Gemini, Suno
  • Deployment: GitHub Pages
